# Day 28 - Simple Calculator

This script performs basic arithmetic operations in a Bash shell.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Prevents division by zero

## Run the script
```bash
bash ./calc.sh
```

## Example
1. Enter the first number
2. Enter the second number
3. Choose an operation from the menu
4. View the result

> This script uses `bc` for arithmetic calculations, so make sure it is installed on your system.
