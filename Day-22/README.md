# Intern Welcome Script

This Bash script welcomes a new intern to the DevOps team.

## What It Does

1. Asks the user to enter their name.
2. Prints a welcome message using that name.

## How to Run

You need Bash to run this script. On Linux or macOS:

1. Make the script executable:

   ```bash
   chmod +x interns.sh
   ```

2. Run the script:

   ```bash
   ./interns.sh
   ```

3. Enter your name when prompted.

## Example

```text
Enter your name: Alex
Welcome Alex to DevOps Team!
```
